# MO. House

One-page landing site for **MO. House** — a rental house with a pool on Fruška gora, Alibegovac (8 km from Novi Sad).

- Bilingual: Serbian (default) and English, with a language switch that remembers the choice.
- Plain HTML, CSS and JavaScript. No frameworks, no build step.
- Single file: `index.html`. Photos in `images/`.

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000
